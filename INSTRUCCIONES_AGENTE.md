# Instrucciones de Sistema: Generación de Protocolo y Sincronización en GitHub

**Conexión**: Este agente debe estar vinculado al repositorio https://github.com/rgarciarojo76-ctrl/risk-analysis

**Rama de Trabajo**: Es obligatorio crear y usar exclusivamente la rama `dev-colaborador`.

**Entorno**:

- Instalar dependencias de Node.js (`npm install`).
- Instalar dependencias de Python (`requirements.txt` en su entorno virtual) si aplica.

**Despliegue Local**: Usar `vercel dev` para previsualizar.

**Sincronización**: Cada avance debe subirse automáticamente mediante `git push origin dev-colaborador`.
